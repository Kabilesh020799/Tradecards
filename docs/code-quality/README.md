# Code-quality reports

These spreadsheets are Designite analysis exports captured before and after the
project's refactoring work. They are retained as historical evidence for comparing
architecture, design, and implementation smells; they are not runtime inputs.

The `before-refactoring/` and `after-refactoring/` directories contain the
corresponding snapshots. Generate future reports outside the source tree and add
them here only when they support a documented comparison.
